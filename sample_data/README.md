# sample_data

Everything in this folder is **fake**. The export zip was generated by
`tests/synthetic.py` — invented names, companies, and emails — so the README
demo and the test suite never touch real contact data.

- `sample-linkedin-export.zip` — a synthetic LinkedIn export (15 fake contacts,
  including duplicates and sparse rows to exercise dedupe and scoring).
- `sample-summary.md` — what `humandb run` produces from it.

**Do not commit real exports or real outputs to this repo.** The `.gitignore`
is set up to refuse them (`*.zip`, `contacts.json`, `contacts.csv`,
`summary.md` at the repo root and in output dirs). Keep your real data on
your own machine.
